# 信息图 / 科普图 提示词规律（专项）

> 统计范围：541 例中筛出 **79 个信息图与科普图案例**（含图鉴、拆解、图谱、工程图、分析报告、学习卡、导览绘本），逐条读过原文。
> 这一类是全库最"重度"的提示词：**中位长度 1696 字符**（全库中位 1044），45 例超过 1500 字符。

---

## 一、先分清：你说的"科普图"和"信息图"其实是两种侧重

| | **科普图**（知识解说型） | **信息图**（结构数据型） |
| --- | --- | --- |
| 目标 | 让人"看懂一个东西" | 让人"看懂一套关系/流程/数据" |
| 视觉母题 | 图鉴、百科书页、博物馆展板、解剖图谱 | 因果链、剖面、流程、对比、时间轴 |
| 核心手法 | 主视觉 + 放大细节 + 材质/寓意标注 | 分区模块 + 引线 + 图表 + 编号 |
| 信息密度 | 中高，讲究"耐看、可收藏" | 高，讲究"逻辑清楚、层级分明" |
| 典型版式 | 竖版 A4 / 9:16 长图，中轴对称 | 方形 1:1 / 横版 16:9 / 分区网格 |
| 代表案例 | 例 8、74、222、296、415、469、544 | 例 1、66、70、71、82、447、494、407 |

两者的提示词骨架**高度重合**（下面第二节），区别只在"重心放在解说还是结构"。实际写作时可以直接用同一套模板，替换第 3、5 段的写法。

---

## 二、这类图的六段骨架（覆盖率来自 79 例实测）

| 段落 | 写什么 | 覆盖率 |
| --- | --- | --- |
| ① **定性开场** | "这不是普通海报，而是兼具图鉴感、百科感、信息结构感、收藏感的模块化科普信息图" | 高频（几乎模板化） |
| ② **主视觉** | 主体是谁、什么姿态、占画面多少（常写 50%–70%）、是否"破框/3D 立体" | 48.1% 提到中心/C 位 |
| ③ **拆解或放大** | 剖面、爆炸视图、局部放大圆窗、结构分层 | 29.1% |
| ④ **标注层** | 引线、编号、箭头、圈注、手写风标签 | 26.6% |
| ⑤ **信息模块群** | 4–8 个模块，每个含"图标 + 标题 + 1–3 行说明" | 24.1% 写明模块数量；60.8% 给出方位 |
| ⑥ **底部总结/评分** | 总结句、评分卡、Top5、对比表、Tips 横幅 | 54.4% 含数据/评分/对比元素 |

再加两个"外壳"要素：

- **标题层级**（主标题 + 副标题 + 英文名/副题）：57.0%
- **背景材质与配色**：41.8%（浅色纸感底 32.9%，暗色科技底 8.9%）

## 三、版式与画幅：这是这类图最大的翻车点

统计发现一个刺眼的事实：**79 例里只有 18 例（23%）明确写了画幅比例**，其余 61 例没写。信息图对版式极度敏感，画幅一错，模块就挤成一团或空成一片。

**按用途选画幅（推荐按此写死）**

| 用途 | 画幅 | 版式特征 |
| --- | --- | --- |
| 小红书/公众号长图科普卡 | **9:16 或 3:4 竖版** | 上标题、中主视觉、下模块，阅读动线自上而下 |
| 打印/A4 图鉴海报 | **A4 竖版** | 中轴对称，左右分栏，底部总结横幅 |
| 工程/系统信息页 | **1:1 方形** | 深色或白底，中央主视觉 + 四周模块 |
| 流程 / 时间轴 / 对比 | **16:9 横版** | 横向串联，箭头贯穿 |
| 九宫格卡片 | **3:4 或 1:1，3×3** | 每格独立成套，方便切图 |
| 系列图（同套多张） | 统一比例 | 版式、字体、色调、背景全一致 |

**版式描述的正确写法**（照着写，模型基本不会乱排）：

```
版式固定为：
- 顶部：主标题 + 副标题 + 导语
- 左侧：结构拆解区，引线标注关键部件，并配局部放大特写
- 右上：材质 / 工艺区，展示真实纹理小样并附说明
- 右中：纹样 / 色彩 / 寓意区，含主色板、纹样样本与文化解释
- 底部：核心总结 + 快速评分卡
```

这段话出自效果最好的一批案例（例 296、218、415），核心是**把版面切成 4–6 个有名字的区域**，而不是说"排版要好看"。

## 四、科普图（知识解说型）的 5 个成熟模板

### 模板 A｜模块化科普百科图（最通用，适合任何主题）

代表案例：例 8、74、222（中英两版同一套写法）

```
根据【主题】生成一张高质量竖版「科普百科图」。
这张图不是普通海报，也不是单纯插画，而是兼具图鉴感、百科感、信息结构感、收藏感的模块化科普信息图。

画面必须包含：
① 一个清晰漂亮的主题主视觉
② 若干局部特征放大细节
③ 多个圆角模块化信息分区
④ 清楚的标题层级与重点标签
⑤ 可视化评分、要点总结或 Top 5 模块

内容栏目自动适配，优先从这些里组合：
基础档案 / 分类信息 / 外观特征 / 习性生态 / 结构组成 / 生长或使用条件 /
养护建议 / 风险与注意事项 / 适合人群 / 优缺点对比 / 快速评分卡

视觉：浅色干净背景、柔和配色、轻阴影、精致小图标、圆角信息框、信息密度高但不拥挤。
文字：中文清晰规整可读，不乱码、不错字。
排除：不要做成普通商业宣传海报，重点突出"知识整理 + 模块信息 + 图鉴式展示"。
规格：【9:16 竖版 / A4】，8K。
```

### 模板 B｜拆解图谱（器物、建筑、产品、生物）

代表案例：例 296（博物馆级中文拆解图鉴）、例 218（科学百科图谱）、例 211（天坛拆解）、例 333（AI 眼镜爆炸图）、例 443（塔可爆炸拆解）

```
请根据【主题】自动生成一张"博物馆图鉴式中文拆解信息图"。
需要：真实写实主视觉 + 结构拆解 + 中文标注 + 材质说明 + 纹样寓意 + 色彩含义 + 核心特征总结。
自动判断最合适的主体对象、结构体系、时代风格、关键部件、材质工艺与色板，用户无需再提供其他信息。

版式：
顶部主标题+副标题+导语｜左侧结构拆解（引线标注关键部件+局部特写）｜
右上材质工艺区（真实纹理小样）｜右中纹样色彩寓意区（主色板+纹样样本）｜底部构成流程图+核心特征总结

风格：国家博物馆展板、文博专题信息图，米白/绢纸白/浅茶色纸感，高级克制专业可收藏。
文字：全部简体中文，清晰规整可读，不要乱码、错字、英文或拼音。
避免：海报感、影楼感、电商感、动漫感、乱标注、错结构、糊字、假材质、过度装饰。
```

**要点**：拆解类必须写清"**拆成几层/几个部件 + 每个部件标注什么**"，例如例 17 写明"9 层内部结构、8 个引线标签"，例 70 写明"12 个标注部件"。

### 模板 C｜人物/文化主题百科海报

代表案例：例 415（东方神话人物志）、例 179（蒸汽朋克星座解剖图谱）、例 396（龙类物种复古百科海报）、例 248（青花瓷解说图谱）

写法特点：

- **先定"档案板块清单"**：神格身份 / 神话源流 / 司职权柄 / 形象特征 / 法器坐骑 / 典故 / 象征寓意 / 文化影响
- **明确风格边界**：例 415 直接列出"不要北欧符文、不要维京图腾、不要哥特边框、不要西幻恶魔角、不要赛博朋克"，把跑偏空间堵死
- **给不确定内容的处理方式**：`不确定的信息不要强行编造，可写"民间传说中多有异文"`（例 415）——这是防模型瞎编的关键一句

### 模板 D｜儿童科普绘本地图

代表案例：例 469（导览式科普绘本）、例 544（幼儿词汇拆解学习卡）、例 11（城市美食地图）、例 18（插画地图信息图）

```
请根据【主题】创作一张「导览式科普绘本」风格插画。
画面 = 大型场景主视觉 + 导览路线 + 可爱导览 IP + 知识站点 + 儿童绘本质感。
设定：主题【…】／画幅【4:3 横版】／主色【明亮清爽儿童友好】／风格【现代儿童科普绘本】。
设计一个原创导览小 IP（小动物/小朋友/拟人化工具），出现 2–3 次，负责开场、指路、收尾。
设置 3–6 个知识站点，用短标签 + 短说明：第1站｜xxx、重点观察｜xxx、小知识｜xxx、为什么｜xxx。
```

### 模板 E｜分析报告型科普图（人像/美妆/穿搭/健康）

代表案例：例 437（面部美学分析报告）、例 364（个人色彩档案）、例 360/348（发型/胡须分析）、例 353（口红推荐报告）、例 183（健身信息图）

```
你是一个【美妆顾问 + 人脸分析系统 + 品牌视觉设计系统】。
基于用户上传照片，生成一张竖版"【主题】分析报告信息图"。

分析层：肤色冷暖 + 气质类型 + 关键特征 → 给出一句结论。
推荐层：3–5 项推荐，每项含名称、类别、适配效果、使用场景。
信息结构：左上=用户输入区｜右上=分析结论｜中部=对比矩阵（核心）｜底部=总结与建议。
视觉：留白充足、细分割线、圆角卡片、克制的品牌色、数据用图表/评分条呈现。
```

## 五、信息图（结构数据型）的 4 个成熟模板

### 模板 F｜因果链信息图（"X 是怎么产生的"）

代表案例：例 66（一件女装诞生的因果链）、例 70（一张照片诞生的因果链）、例 71（相机成像剖面）

```
【类型】technical infographic｜【主题】XX 诞生的因果链 THE CAUSAL CHAIN OF XX
【副标题】从 A，到 B　FROM A TO B
【中心】主体结构的等距爆炸视图（标注 N 个部件）
【左栏】因果链 13 步：01 现实存在 → 02 … → 13 记忆长存
【右栏】八大模块：原理 / 结构 / 工艺 / 参数 / 应用 / 对比 / 常见误区 / 延伸
【文字】每步带一句说明，编号用两位数统一格式
```

**为什么有效**：它把"讲原理"变成了"讲一条链"，模型有明确的先后顺序可依，不会把内容摊平。

### 模板 G｜工程 / 系统手册页

代表案例：例 447（现代地铁工程信息图）、例 494（电动巴士工程信息图）、例 407（Neuro-AI 系统信息图）、例 82（光路实验装置图）

```
Create a premium square "{主题} infographic", designed as a beautifully curated
engineering handbook page rather than an advertisement.
• 1:1 square composition
• 背景：【深色科技底 + 蓝图/电路示意】或【纯白棚拍底】
• 配色：【深海军蓝 / 石墨黑 / 钢灰 + 一个强调色】
• 中央：主体 3D 渲染或剖面图
• 模块：圆角信息卡 + 细分割线 + HUD 风格分隔符
• 标注：组件名称、参数、工艺流程、安全说明
• 文字：清晰的编辑式字阶，标题大、正文小而清楚
```

### 模板 H｜流程 / 步骤 / 食谱图

代表案例：例 14（番茄炒蛋 Z 字形动线食谱）、例 55（菜品制作流程图）、例 341（数学学习表）

```
【规格】9:16 竖版信息图，米色手工纸背景，带纤维纹理
【配色】主色 + 辅色 + 墨线（给出具体色值，如 #E23A28 / #F2C94C / #6FCF97）
【排版】顶端大标题 → 中间 Z 字形动线 → 底部全景成品
【每个步骤】步骤名（图形）+ 说明 + 秘技 + 心得
【底部】成品插图 + 署名栏
```

> 关键技巧：**步骤类一定要写"动线"**（Z 字形、蛇形、顺时针），否则模型会把步骤排成一列小格子。

### 模板 I｜数据 / 卡片 / 宫格信息图

代表案例：例 51（7 日穿搭信息图，7 列 × 9 类元素）、例 235（九宫格助眠指南，逐格给出标题与正文）、例 112/171（网格卡片）、例 83（赛事数据海报）、例 456（2×2 可视化地图）

```
3 列 × 3 行九宫格，边界清晰，方便直接切图发布。
每一格：标题 + 正文（逐字给出） + 配图元素。
每格内容居中，不要把文字压在分割线附近，格间留明显间隔。
整体风格统一，像同一套系列卡片。
```

## 六、文字：科普图最容易毁掉的地方

79 例中大量案例把文字要求写成"硬性条款"，值得直接抄：

**1）标题层三件套**

```
主标题：【中文名】（书法体 / 宋体 / 黑体，占顶部 1/6）
副标题：【一句话定位】
英文名：【English Name】 + 细短横线
```

**2）正文层的三条铁律**（例 296、218、415 都出现了）

```
所有文字必须为简体中文，清晰、规整、可读；
不要乱码、不要错字、不要拼音、不要无意义符号；
不确定的内容不要编造，可写"相关记载较少"。
```

**3）数字与单位写法**：参数一律连单位写死，如 `λ = 632.8 nm`、`100W`、`40–60 分钟`、`RIR 1–3`。写死数字比写"标注参数"的成图质量高一档。

**4）双语只用在标题与关键标签**：这一类里带中英对照的只有 14/79，且绝大多数是"中文主标题 + 英文副标"或"中文标注 + 英文栏目标题"，正文仍以单语为主。

## 七、配色与材质：三套成熟视觉系统

| 系统 | 写法 | 适用 | 案例 |
| --- | --- | --- | --- |
| **纸感文博系** | 米白/绢纸白/浅茶色纸底 + 纤维纹理 + 细墨线 + 朱砂点缀 | 传统文化、器物、生物图鉴、可收藏 | 例 296、415、218、179、396 |
| **现代白底系** | 纯白/极浅灰底 + 大留白 + 圆角卡片 + 单一强调色 + 精致小图标 | 学习卡、健康科普、App 风信息图 | 例 8、222、341、339、437 |
| **暗色科技系** | 深海军蓝/石墨黑 + 蓝紫辉光 + 蓝图或电路叠加 + 金属反射 | 工程、系统、AI、硬件、赛事 | 例 407、447、494、83 |

**材质描述要落到具体词**：羊皮纸、手工和纸、哑光厚艺术纸、亚麻纹理、屏幕玻璃、拉丝钛金属、陶瓷、冷凝水……全类 39.2% 的案例写了材质/工艺，这是"图鉴感"的主要来源。

## 八、两种"内容由谁决定"的写法（各有适用）

| 写法 | 句式 | 何时用 |
| --- | --- | --- |
| **交给模型推演**（16.5%） | `根据【主题】自动判断最合适的主体对象、结构体系、色彩方案与版式，用户无需再提供其他信息` | 快速出图、主题宽泛、做系列封面 |
| **自己把内容写死** | 逐模块给出标题、文案、参数、色号 | 对准确性有要求、要对外发布、要复用同一版式 |

推荐做法：**结构交给模型（版式、配色、构图），内容自己给（模块标题、关键数据、文案）**——既能保持版式稳定，又不会出现事实性错误。

## 九、负向清单：这类图必须写的排除项

```
不要做成普通商业宣传海报（信息图类最常见的跑偏）
不要杂乱堆砌、不要硬拼贴
不要乱码、错字、拼音、无意义符号
不要卡通感 / 动漫感 / 影楼感 / 电商感（按题材取舍）
不要出现与主题不符的文化元素（如东方题材里的北欧符文、赛博朋克）
不要过度装饰、不要廉价模板感
不使用卡片框与圆角块（如果走的是 Apple 极简白底路线，例 339）
```

> 注意最后一条是"反向约束"：不是所有科普图都要圆角卡片。走极简高级路线时要明确写 `不使用卡片、圆角框、复杂底纹、淡黄纸张质感`。

## 十、避坑对照表（症状 → 改法）

| 症状 | 原因 | 改法 |
| --- | --- | --- |
| 模块挤成一团 / 大片空白 | 没指定画幅与分区 | 写明画幅 + 顶部/左/右/底四区划分 |
| 文字乱码、缺字 | 没给文字内容与约束 | 逐字写出标题文案 + "简体中文、清晰、不乱码" |
| 看起来像广告海报 | 没写"这不是海报" | 开场定性句 + 排除海报感、电商感 |
| 内容空泛、没干货 | 全交给模型自由发挥 | 给出 4–8 个模块的具体名称与数据 |
| 结构画错、标注乱指 | 没列部件清单 | 列出部件数量与名称（如"9 层结构、8 个标注"） |
| 画风跑偏（出现西幻/动漫元素） | 没划风格边界 | 写"不要 XX、不要 YY"的负面清单 |
| 事实错误、编造内容 | 模型自行补知识 | 关键数据自己给；不确定处写"可标注异文" |
| 系列图风格不统一 | 每张独立描述 | 固定版式文案 + 只替换主题变量 |

## 十一、可直接复制的两块"通用骨架"

### 骨架 1｜科普图鉴（竖版，最常用）

```
根据【主题】生成一张竖版「科普百科图」，兼具图鉴感、百科感、信息结构感与收藏感。

【主视觉】中央为【主体】的超写实/精细线稿形象，占据画面约 60%，姿态【…】，
背景【浅米色手工纸 / 纯白棚拍】，带【细微纹理与柔和阴影】。

【版式】顶部：中文主标题【…】+ 副标题【…】+ 英文名【…】；
左侧：结构/特征解说（引线标注 + 局部放大圆窗 2–3 处）；
右上：材质工艺区（真实纹理小样 + 说明）；
右中：色板 + 纹样/要点速记；
底部：核心总结句 + 快速评分卡（3–5 项打分）。

【模块（自动填充）】基础档案 / 外观特征 / 结构组成 / 使用或生长条件 / 风险与注意 / 优缺点对比。

【文字】全部简体中文，清晰规整可读，不要乱码、错字、拼音；数字与单位写清楚。
【风格】高级博物图鉴 + 现代百科书页 + 生活方式知识卡，克制、专业、可收藏。
【排除】不要海报感、电商感、动漫感；不要杂乱堆砌、不要硬拼贴。
【规格】9:16 竖版，8K。
```

### 骨架 2｜结构信息图（方形/横版，讲原理）

```
创作一张【主题】的工程手册式信息图（engineering handbook page），不是广告。

【规格】1:1 方形（或 16:9 横版）
【背景】深海军蓝 + 蓝图/电路示意叠加；【配色】石墨黑、钢灰 +【强调色】
【中央】主体【…】的等距爆炸视图，标注【N】个部件；每个部件带名称 + 一句功能说明
【模块】原理概述 / 结构分层 / 工作流程 / 关键参数 / 应用场景 / 常见误区 / 对比表 / 总结
【标注】细引出线 + 编号 + 箭头指向，编号用 01–08 统一格式
【文字】标题巨大、副标题克制、正文小而清晰；中文准确、不乱码
【排除】不要杂乱、不要拼贴感、不要卡通元素
```

## 十二、出手前的 8 条自检

1. 写画幅了吗？（9:16 / 3:4 / A4 / 1:1 / 16:9）
2. 写"这不是海报，是科普信息图"了吗？
3. 版面切成 4–6 个有名字的区域了吗？
4. 模块数量和名称给了吗？（4–8 个）
5. 要出现的文字逐字写了吗？加了"简体中文、不乱码"吗？
6. 标注/引线/放大镜说了吗？
7. 背景材质与配色说了吗？（纸感 / 白底 / 暗色三选一）
8. 排除项写了至少两条吗？（不要海报感、不要杂乱、不要乱码）
