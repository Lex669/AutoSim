# 信息图骨架推导法

规律来源：`sample_prompt/` 的六份优秀样本，以及 `sample_prompt/信息图与科普图提示词规律.md`（541 例中筛出的 79 个信息图 / 科普图案例统计）。素材只供人阅读，不必在生成提示词时引用。

## 一句话规律

优秀的信息图提示词不靠形容词堆高级感，而是**先把信息结构写成清单**——画幅多宽、切几个有名字的区域、每块叫什么、有几项、拆成几个部件、文字逐字写什么——再交给模型画。画质靠"单一超写实主视觉 + 分区信息板"，稳定性靠"画幅 + 数量约束 + 写死的文字 + 负面清单"。

## 第一步：判子类型

先分清两种侧重，再落到具体子类型。两者骨架相同，区别只在重心放在解说还是结构：

| | 科普图（知识解说型） | 信息图（结构数据型） |
| --- | --- | --- |
| 目标 | 让人"看懂一个东西" | 让人"看懂一套关系 / 流程 / 数据" |
| 视觉母题 | 图鉴、百科书页、博物馆展板、解剖图谱 | 因果链、剖面、流程、对比、时间轴 |
| 典型画幅 | `9:16` / `3:4` / `A4` 竖版，中轴对称 | `1:1` / `16:9` / 3×3 网格，分区并列 |

写进 `subtype`，并按它决定主线：

| 子类型 | 识别信号 | 主线推导 |
| --- | --- | --- |
| 科普图鉴 / 百科卡 |「介绍一下××」「图鉴」「科普」 | 主视觉 → 外观特征 → 结构组成 → 材质工艺 → 使用或生长条件 → 速记与评分卡 |
| 结构拆解 / 剖面 / 爆炸图 | 器物、建筑、产品、生物、装置 | 拆成几层或几个部件（写死数量）→ 每个部件标注名称 + 一句功能 |
| 系统 / 工程手册页 | 装置、设备、工艺、链路、生产、运维 | 抽 4–8 个有序环节，构成从输入到输出的链路 |
| 因果链 |「××是怎么产生的」「诞生」「一张××的由来」 | 一条两端明确的链，编号统一两位数，每步一句说明 |
| 流程 / 步骤 / 食谱 | 做法、步骤、教程 | 每步"图形 + 说明 + 秘技" + 一条动线（Z 字形、蛇形、顺时针） |
| 数据 / 宫格卡片 |「×条」「×个」「清单」「指南」 | N 列 × M 行宫格，每格标题 + 正文 + 配图元素，格间留白、方便切图 |
| 地图 / 导览绘本 | 地点、路线、城市、儿童科普 | 大场景 + 导览路线 + 出现 2–3 次的导览 IP + 3–6 个知识站点 |
| 分析报告 / 画像 | 人像、美妆、穿搭、健康、测评 | 输入区 → 分析结论 → 对比矩阵（核心） → 底部建议 |
| 人物 / 文化档案 | 神话、历史人物、文化专题 | 档案板块清单：身份 → 源流 → 特征 → 器物 → 典故 → 象征 → 影响 |

## 第二步：定画幅（写进 `canvas`）

信息图对版式极度敏感：样本里只有 23% 写了画幅，而画幅一错，模块要么挤成一团、要么空成一片。按用途选一个写死，`canvas.orientation` 里再说一次。

| 用途 | `aspect` | 版式特征 |
| --- | --- | --- |
| 长图科普卡（小红书 / 公众号） | `9:16` | 上标题、中主视觉、下模块，阅读动线自上而下 |
| 图鉴卡 / 打印页 | `A4` 或 `3:4` | 中轴对称，左右分栏，底部总结横幅 |
| 工程 / 系统信息页 | `1:1` | 中央主视觉 + 四周信息卡 |
| 流程 / 时间轴 / 对比 | `16:9` | 横向串联，箭头贯穿 |
| 九宫格卡片 | `3:4` 或 `1:1` | 3×3 网格，每格独立成套，方便切图 |

## 第三步：推导主线

主线要**同时**驱动三处，三者必须一一对应：

1. `centerpiece` 的剖切层级或部件排布；
2. 编号面板的顺序（每个环节至少一个面板）；
3. `layout.bottom_row` 底部流程条的分步标签。

### 推导示例：相干衍射成像 CDI

环节：相干光源 → 针孔与光束整形 → 样品与过采样衍射 → 远场探测器采集 → 相位恢复迭代 → 重建图像与分辨率评估。

映射结果：

- 主视觉：三维剖切的 CDI 实验腔，光路自左向右贯穿，发光青色束线连接各环节；
- 面板：01 相干光源 / 02 光束整形 / 03 样品与过采样 / 04 远场采集 / 05 相位恢复 / 06 重建评估；
- 底部流程条：相干照明 → 过采样衍射 → 强度采集 → 相位恢复 → 重建成像。

完整成品见 `references/examples/cdi-infographic.json`；科普图鉴型见 `references/examples/heritage-infographic.json`。

## 第四步：把版面切成 4–6 个有名字的区域

不要写"排版要好看"，要写出方位与栏目名。效果最好的一批案例都是这么写的：

```
顶部：主标题 + 副标题 + 导语
左侧：结构拆解区，引线标注关键部件，配局部放大圆窗 2–3 处
右上：材质 / 工艺区，真实纹理小样 + 说明
右中：色板 / 纹样 / 要点速记区
底部：核心总结 + 快速评分卡（3–5 项）
```

`layout` 的键就按这张表来：`top_left`、`top_right`、`left_column`、`right_column`、`center_overlay`、`bottom_row`。

## 第五步：按公式写面板

每个面板都写成 **编号 + 中文标题 + 元素类型 + 数量**：

> `04` `远场衍射采集` —— `1 张衍射图样示意 + 1 张探测器读出链示意 + 4 条图例`（`count: 4`）

拆解类必须写清"拆成几层 / 几个部件 + 每个部件标注什么"，例如 `9 层内部结构 + 8 个引线标签`、`12 个标注部件`。配套的中文图例标签放进 `labels`，每条只写几个字。宁可多几个面板，也不要把一个面板写成一段话。

## 第六步：写死文字与数字

- **标题三件套**：主标题（中文名，≤16 字）+ 副标题（一句话定位）+ 英文名或副题（用细短横线分隔）。
- **正文三条铁律**：所有文字为简体中文、清晰规整可读；不要乱码、错字、拼音、无意义符号；不确定的内容不要编造，可写"相关记载较少 / 民间传说中多有异文"。
- **数字与单位写死**：`λ = 632.8 nm`、`1300 ℃ 一次烧成`、`40–60 分钟`，比"标注参数"稳一档。
- **双语只用在标题与关键标签**，正文保持单语。

## 第七步：选一套视觉系统

| 系统 | 写法 | 适用 |
| --- | --- | --- |
| 纸感文博系 | 米白 / 绢纸白 / 浅茶色纸底 + 纤维纹理 + 细墨线 + 朱砂点缀 | 传统文化、器物、生物图鉴、可收藏 |
| 现代白底系 | 纯白 / 极浅灰底 + 大留白 + 圆角卡片 + 单一强调色 + 精致小图标 | 学习卡、健康科普、App 风信息图 |
| 暗色科技系 | 深海军蓝 / 石墨黑 + 蓝紫辉光 + 蓝图或电路叠加 + 金属反射 | 工程、系统、AI、硬件、赛事 |

`style` 里要落到具体材质词：羊皮纸、手工和纸、哑光厚艺术纸、亚麻纹理、拉丝钛金属、陶瓷、屏幕玻璃、冷凝水……"图鉴感"基本来自这些词。

注意"反向约束"：走极简白底路线时，要明确写 `不使用卡片、圆角框、复杂底纹、淡黄纸张质感`。

## 第八步：写负面清单

`avoid` 从下面的词库里挑 ≥5 条，其中**必须含"海报感"和"乱码 / 错字"两类**：

> 海报广告感、电商详情页感、影楼感、动漫或卡通风、杂乱堆砌与硬拼贴、糊字乱码与拼音、结构或部件错误、假材质、过度装饰、霓虹过载、大段文字段落、与主题不符的文化元素

## 自检（出手前 8 条）

1. `canvas.aspect` 写了吗？
2. `type` 是否点明了"这是什么图、不是什么图"？
3. 版面切成了 4–6 个有名字的区域吗？
4. 模块 4–8 个，且每个都有标题与数量吗？
5. 要出现的文字逐字写了吗，并写了"简体中文、不乱码"吗？
6. 引线、编号、局部放大圆窗说了吗？
7. `style` 里写了背景材质与配色吗？
8. `avoid` ≥5 条，含"海报感"与"乱码"了吗？
