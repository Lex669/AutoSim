# 海报骨架推导法

规律来源：`sample_prompt/poster/` 下的四份优秀样本（字体肖像、编辑艺术、水彩旅行、拼贴电影感）。

## 一句话规律

海报样本都是**一段连贯的画面指令 + 写死的文字层**：先给风格融合（"现代旅行海报与水彩拼贴的融合"），再给主体与世界，然后把每条文字的原文、位置、层级逐条列清，最后用工艺词与负面清单把质感焊死。

## 第一步：选子类型

| 子类型 | 视觉特征 | 适用主题 |
| --- | --- | --- |
| 字体肖像 | 高对比黑白、剪影与负空间、文字嵌进形体 | 人物、创作者、展览主视觉 |
| 编辑艺术 | 超现实建筑、柔和高级配色、胶片颗粒 | 城市、未来想象、品牌主视觉 |
| 旅行 | 水彩与照片拼贴、暖金与青灰、地标与人群 | 城市、地点、节庆 |
| 拼贴 | 撕纸边、网点、墨迹溢出、套色错位 | 电影感、复古、文化主题 |
| 极简几何 | 大留白、干净色块、单一焦点 | 学术活动、发布会、讲座 |

## 第二步：写主视觉与构图

`centerpiece.subject` 写清谁 / 什么、在哪、周围有什么；`centerpiece.composition` 写清主体位置、地平线高度、视线方向与留白安排——留白位置要与文字层对得上。

## 第三步：把文字层写死

海报的文字不是装饰，是构图的一部分。`header.text_blocks` 逐条给出：

- `text`：原文（中文；专有名词可保留原文但要夹在中文里）
- `position`：`左上`、`主标题下方`、`左下`、`右下竖排`、`底部信息条`
- `level`：`主标题`、`副标题`、`小字信息`、`装饰性小字`

常用文字角色：主标题、副标题、地名与坐标、日期或届次、落款或展览名、竖排装饰小字。

## 第四步：写版面分区与装饰

`layout.sections` 从上到下写分区（如"天空留白区（主标题）→ 中景建筑带 → 前景水岸 → 底部信息条"）；`layout.decorations` 写装饰与工艺元素。

工艺词库（至少挑 3 条）：

> 纸纹与纤维、印刷网点、油墨溢出、套色轻微错位、撕纸边、胶片颗粒、水彩晕染、半透明几何色块、细边框线、手写笔迹、复写与复印颗粒

## 第五步：写风格与负面清单

`style` 用"两种类型的融合"起头，再补配色与气质：

> 现代旅行海报与水彩拼贴的融合；暖金与青灰配色；纸张颗粒与轻微印刷错位；空气感、安静、高级克制

`avoid`（≥3 条）常用：

> 光泽的现代商业感、摄影写实堆砌、杂乱元素、廉价促销海报感、卡通插画感、过度霓虹

## 画幅

`canvas.aspect` 默认 `4:5` 竖版（样本一致）。需要横版时写 `16:9` 或 `3:2`，并在 `orientation` 里注明。

## 自检

- 是否有明确的风格融合句？
- `text_blocks` 是否每条都有原文、位置、层级？
- 装饰与工艺词是否 ≥3 条？
- `canvas.aspect` 是否写了？
- 文案是否全中文（专有名词可保留原文）？
- `avoid` 是否 ≥3 条？
