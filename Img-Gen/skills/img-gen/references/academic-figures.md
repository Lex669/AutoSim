# 学术配图提示词模板

面向论文、海报与期刊场景。提示词要写成一段连贯的详细中文描述（画面类型 → 主体 → 布局 → 配色 → 光线 → 风格），不要写成关键词列表。

## 通用要点

- 图中文字少而精：只保留标题或缩写词（≤12 字），用引号给出原文，例如：图中居中显示标题 "Metasurface"。
- 不要让模型渲染复杂公式、数据表格、精确曲线数值——这些后期叠加更可靠。
- 学术风格关键词：扁平矢量插画、简洁线条、低饱和配色、白色/浅色背景、信息层次清晰、无多余装饰。
- 尺寸建议：图形摘要/TOC 用 2048*1152 或 2048*1536；方形示意图 2048*2048；竖版海报/期刊封面 1536*2048。

## 1. 图形摘要（Graphical Abstract）

结构：输入 → 方法 → 输出 的横向叙事，单行或两行布局，一眼看懂论文做了什么。

提示词骨架：

> 画面是一张学术论文图形摘要，横向构图，浅色干净背景。从左到右依次是：……（输入对象描述）→……（核心方法/装置描述，包含关键组件与材料）→……（输出/性能/应用描述）。各部分之间用简洁的箭头连接，整体为扁平矢量科研插画风格，配色为……（如深蓝、青色与橙色点缀），画面中仅出现文字 "……"。

## 2. TOC 图 / 文章配图

结构：一个核心视觉隐喻 + 少量辅助元素，强调一眼可读、有记忆点。

提示词骨架：

> 画面是一张学术论文 TOC 插图，方形构图。主体是……（核心隐喻，如"纳米结构上的局域光场"），周围点缀……（少量相关元素），风格为现代科研插画，色彩……，背景为……，画面中不出现文字。

## 3. 方法 / 装置示意图

结构：按真实空间关系逐一描述组件位置（顶部/中部/底部、左侧/右侧、连接关系），标签用简短英文。

提示词骨架：

> 画面是一张技术装置示意图，横向构图，白色背景。中央是……（装置主体），其上方是……，下方是……，左侧的……通过……连接到主体，右侧输出……。各部件用简洁线条与色块区分，关键部件旁有简短标签 "……"，整体为工程制图风格的扁平插画，配色……，无阴影与多余装饰。

## 4. 机理 / 概念图

结构：用视觉隐喻描述抽象过程（阶梯、通道、网格、能级、漏斗等），明确方向与因果。

提示词骨架：

> 画面是一张科学机理概念图，表现……过程：……（用视觉隐喻逐步描述机制），箭头指示从……到……的方向，配色由……渐变到……，风格为简洁的扁平插画（或柔和 3D 渲染），背景为深色/浅色以突出主体，画面中不出现文字。

## 5. 期刊封面

结构：一个有冲击力的主视觉 + 上方留白区（刊名等文字一律后期叠加，不要让模型写字）。

提示词骨架：

> 画面是一张学术期刊封面插画，竖版构图。主视觉是……（与研究主题相关的艺术化场景，描述细节、光线与氛围），上方约三分之一区域相对简洁、留白（用于后期叠加刊名与期号），整体风格兼具科学感与艺术感，色彩……，细节丰富，高分辨率质感。

## 示例（供参考语气与细节密度）

> 画面是一张横向学术论文图形摘要，浅灰白背景，扁平矢量插画风格。左侧是一束彩色入射光照射到中央的超表面芯片上，芯片表面排列着周期性纳米柱阵列，呈深蓝与青色渐变；右侧分出三束不同颜色的衍射光，分别指向三个小图标：成像镜头、传感器、天线。元素之间用细箭头连接，整体配色为深蓝、青色与橙色点缀，构图干净平衡，图中仅出现文字 "Metasurface"。
