# PPT 汇报 / 答辩图片提示词模板

面向组会汇报、开题/中期/毕业答辩、项目路演。优先 16:9（2048*1152）；传统 4:3 用 2048*1536。

## 通用要点

- 给文字留白：明确描述"画面某侧留出大面积干净区域，用于后期放置标题/文字"。标题、姓名、编号一律后期叠加，不要让模型渲染。
- 与 PPT 主题色一致：在提示词中写明主色与点缀色（如"深蓝与金色"、"学术红与浅灰"）。
- 同一套 PPT 保持同一风格关键词：扁平插画 / 微立体渲染 / 科技感渐变 / 学术简约。
- 若 API 对 16:9 尺寸报错，回退 2048*2048，交付时说明可后期裁剪。

## 1. 封面页

提示词骨架：

> 画面是一张 PPT 封面背景图，16:9 横向构图，主题为……（如"光子芯片 / 深度学习 / 材料仿真"）。主视觉位于画面……侧：……（与研究相关的视觉元素，描述形态、光线与质感），另一侧留出大面积干净区域用于后期放置标题与姓名。配色为……，风格为……（科技感渐变 / 扁平插画 / 微立体渲染），画面中不出现任何文字。

## 2. 目录页 / 章节过渡页

提示词骨架：

> 画面是一张 PPT 章节过渡页背景，16:9 构图。以……（抽象几何、主题符号等视觉元素）为主体，位于画面一侧，另一侧留白用于后期放置章节编号与标题。配色延续……，风格简洁大气，画面中不出现文字。

（章节编号 01/02/03 与标题一律后期叠加。）

## 3. 内容页配图

提示词骨架：

> 画面是一张 PPT 内容页插图，用于解释……（概念 / 流程 / 对比），横向构图。主体为……，布局为……，扁平矢量风格，配色与主题一致（……），背景为白色/浅色，仅保留简短标签 "……"（或完全无文字）。

## 4. 概念背景图（全页底图）

提示词骨架：

> 画面是一张低对比度的 PPT 全屏背景图，16:9。抽象表现……（主题意象，如"数据流 / 光学衍射 / 分子结构 / 仿真网格"），色彩柔和（……），整体偏暗（或偏浅）以保证前景文字清晰可读，无任何文字与具体人物。

## 5. 致谢页

提示词骨架：

> 画面是一张 PPT 致谢页背景，16:9，温暖简洁的氛围。主体为……（如校园建筑剪影 / 实验室场景的扁平插画 / 柔和渐变与光斑），中央或一侧留出空白用于后期放置致谢文字，配色……，风格与整套 PPT 统一，画面中不出现文字。

## 示例（答辩封面背景）

> 画面是一张毕业答辩 PPT 封面背景图，16:9 横向构图。右侧主体是微立体风格的实验室场景：光学平台上排列着透镜与激光光路，发出柔和的蓝色光束，金属器件带有细腻高光；左侧为大面积浅色留白区域，用于后期放置论文标题与答辩人信息。整体配色为深蓝、浅灰与少量金色点缀，风格现代、干净、有科技感，画面中不出现任何文字。
